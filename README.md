# Testing cargo-dist

cargo-dist automates building binaries and creates installation scripts.

## install this binary

**MacOS/Linux**
```
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/tofoss/cargo-dist-test/releases/download/v0.4.4/dist-test-installer.sh | sh
```

**Windows**
```
powershell -ExecutionPolicy Bypass -c "irm https://github.com/tofoss/cargo-dist-test/releases/download/v0.4.4/dist-test-installer.ps1 | iex"
```
